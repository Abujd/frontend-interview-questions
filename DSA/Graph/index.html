🌐 Graph — DSA Interview Notes

Core concepts, graph types, traversal methods and the most important interview patterns.

1. What is a Graph?

A Graph is a non-linear data structure consisting of vertices (nodes) and edges that represent relationships between nodes.

Example

A ---- B
|      |
|      |
C ---- D

Nodes: A, B, C, D

Edges: A-B, A-C, B-D, C-D

2. Important Graph Terminology

Vertex / Node

A point in the graph representing an entity.

Edge

A connection between two vertices.

Degree

Number of edges connected to a vertex.

Path

A sequence of vertices connected through edges.

Cycle

A path that starts and ends at the same vertex.

Connected Graph

Every vertex can be reached from every other vertex.

Weighted Graph

Each edge has an associated cost, distance or weight.

Connected Component

A group of vertices where every vertex is reachable from another vertex in the same group.

3. Advantages of Graphs

  • Excellent for representing relationships.
  • Can model complex networks.
  • Useful for finding paths and connections.
  • Supports shortest-path problems.
  • Can represent dependencies between entities.
  • Useful for network, routing and recommendation problems.

Real-world Examples

Google Maps Social Networks Airline Routes Computer Networks Dependencies Recommendation Systems

4. Types of Graphs

Type Meaning
Undirected Edges have no direction.
Directed Edges have a direction.
Weighted Edges contain weights/costs.
Unweighted All edges have equal cost.
Cyclic Graph contains at least one cycle.
Acyclic Graph contains no cycles.
Connected Every node is reachable from another node.
Disconnected Graph contains multiple components.
DAG Directed Acyclic Graph.

5. Graph Representation

Adjacency List ⭐

Stores the neighbors of every node. 

const graph = {
  A: ["B", "C"],
  B: ["A", "D"],
  C: ["A", "D"],
  D: ["B", "C"]
};

Best choice for most coding interview problems.

Adjacency Matrix

Uses a 2D matrix to represent connections between vertices. 

[
  [0, 1, 1],
  [1, 0, 0],
  [1, 0, 0]
]

6. Graph Traversal Methods

🔵 BFS — Breadth First Search

Visits nodes level by level.

Uses a Queue. 

Queue
  ↓
Start → Neighbors → Next Level
Common uses:
  • Shortest path in an unweighted graph
  • Level-order traversal
  • Minimum number of steps
  • Multi-source BFS

🟢 DFS — Depth First Search

Explores as deeply as possible before backtracking.

Uses Stack / Recursion.

Common uses:
  • Cycle detection
  • Connected components
  • Backtracking
  • Topological sorting
  • Path existence

⚡ BFS vs DFS

BFS DFS
Queue Stack / Recursion
